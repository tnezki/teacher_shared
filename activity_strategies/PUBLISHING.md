# Activity Strategies — public, versioned shared resource

The self-contained index.html is a published **copy** of the canonical local
CPM_Tools/common/activity_strategies/ directions page (v54, 53 strategies).

Public student/co-teacher link:
https://tnezki.github.io/teacher_shared/activity_strategies/

This repository contains only public classroom directions, no student records.
When the canonical common resource changes, prepare and verify a new shared
copy in a Curriculum Transfer package, then let the teacher review, commit
and push teacher_shared. GitHub Pages deploys after the push. CPM Tools still
uses the local offline copy even when GitHub is unavailable.

Do not edit this published copy as the canonical resource.
