What We Need to Know

Tables, Graphs & Constant Change
Learning focus | LG 02-ican-4 / LG 03-ican-1

• I can recognize constant additive change in a table.

• I can compare vertical change with horizontal change.

• I can connect a table, graph, and equation that describe the same linear pattern.

Vocabulary | Highlight the important words

Linear relationshipA relationship that has a constant rate of change and graphs as a straight line.
Constant differenceThe same change in output for each equal change in input.
Horizontal change (Delta x)The difference between x-coordinates of two points; movement left or right.
Vertical change (Delta y)The difference between y-coordinates of two points; movement up or down.
SlopeThe ratio of vertical change to horizontal change, Delta y / Delta x.
Starting valueThe output at input zero; where a linear graph crosses the y-axis.

Meaning & Method | Rewritten review notes

1. Compare equal input intervals when checking for a linear pattern. A constant output difference is meaningful only when the input step is constant.

2. Compute slope as change in y divided by change in x. Keep the SAME point order in numerator and denominator.

3. For a linear rule y = mx + b, m is the slope and b is the output when x = 0.

Review & Preview

Independent practice. A star marks a useful quick diagnostic for the November 10 test.
1 Find the slope of a table with x-values 0,2,4,6 and y-values 6,12,18,24. Explain each change.
ANSWER / TEACHING NOTE

Δy = +6 for Δx = +2, so slope = 3.

2 A line passes through (0,6), (2,10), and (4,14). Find its slope and starting value.
ANSWER / TEACHING NOTE

Slope = (10 - 6)/(2 - 0) = 2; starting value = 6.

3 ★ The table (0,8), (1,5), (2,2), (3,-1) is linear. Find slope and write the rule.
ANSWER / TEACHING NOTE

m = -3 and b = 8, so y = -3x + 8.

Review & Preview

4 ★ Compare: Pattern A adds 2 to the output for each +1 input. Pattern B adds 4. Which graph is steeper? Explain.
ANSWER / TEACHING NOTE

B is steeper: its positive slope 4 is greater than A’s positive slope 2.

5 Spiral: Is {(1,2),(1,2),(3,5)} a function? State the domain and range.
ANSWER / TEACHING NOTE

Yes; repeating exactly (1,2) does not violate the function rule. Domain {1,3}; range {2,5}.

6 Preview: A runner gains 18 meters in 3 seconds. What is the average rate of change, including units?
ANSWER / TEACHING NOTE

18 m / 3 s = 6 m/s.
